# CivicConnect wireframes (Milestone 2)

Low-fidelity, clickable wireframes for PED v2.0 §10. They show structure and behaviour, not final styling.

## How to view

- **Clickable version:** open `index.html` in any browser (download the file, then double-click it). If GitHub Pages is enabled for this repository, it is also at `https://<owner>.github.io/<repo>/docs/design/wireframes/`.
- **Static screenshots:** see the `screenshots/` folder (the same images as PED v2.0 Figures 10-1 to 10-11).

## What you can do in the prototype

- Use the tabs at the top to jump between screens, grouped by role: Access, Requester, Staff, Management.
- Click rows, buttons and dashboard tiles to move between screens, as a user would.
- **Phone 390px** shows the mobile layout; **Markers on/off** shows or hides the numbered design notes.
- The panel on the right explains each numbered marker and links it to a REQ, ASR or decision ID.
